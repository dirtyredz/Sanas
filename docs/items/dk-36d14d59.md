# Meeting context and manual assistance: pre-Start context, live edits, typed questions, More detail, Ask the audience


From the first real presentation (Constellation, 2026-10-30): the job-level notes could not follow a meeting that changed on the fly, and the owner had no way to type into Sanas mid-meeting (fell back to typing questions to Claude Code). Slides were retired on 2026-11-04 (owner decision, docs/DECISIONS.md); this item now covers meeting context and manual assistance only.

Acceptance:
- Per-meeting context before Start: the Live page has a Meeting context box beside the job picker (works with Unsorted); its text is saved with the meeting at Start (revision 0). The draft survives tab switches, job changes and a failed Start, and is cleared once the meeting is live.
- Per-meeting context during the meeting: the owner can edit that free-text context from the Live page or the overlay's Context; Apply applies immediately to that meeting's answers and coaching, without stopping the meeting. Job context stays the default; meeting context is saved with the meeting.
- Typed input in the overlay: type a question or instruction and get an answer from the same answer path (job + meeting context + transcript). Keyboard-first; does not steal focus from another app until clicked.
- 'More detail' button on an answer card: expands that answer with deeper specifics (same grounding), shown in place or as a follow-up card.
- 'Ask the audience' button: suggests one good question to put to the audience based on what was just covered and the context.
- Meetings that use none of this behave as today.

Status 2026-11-04: pre-Start context, live Apply (Live page + overlay), typed input, More detail and Ask the audience are implemented and covered by unit tests; the pre-Start box, failed-Start draft retention and the saved meeting's context were checked in an isolated-profile dev launch; the live Live-page and overlay editors showing the Start text were checked in the browser preview (a real live meeting needs paid Deepgram). Owner acceptance in a real meeting is still open.
