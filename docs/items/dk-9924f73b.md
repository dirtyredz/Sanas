# Settings: remember the last page and find a setting across pages

Paged Settings (2026-11-01) always opens on API keys, and Ctrl+F no longer finds a setting on another page (the trade-off recorded in DECISIONS). Options: remember the last page for the session; a small filter box over the index that matches field labels and jumps to the page. No existing entry point opens Settings at a section today; if one is added (e.g. a missing-key notice on Live), useSettingsPager would take an initial page.
