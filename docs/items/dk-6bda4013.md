# npm prepare fails in linked worktrees (ENOTDIR on .git/hooks)


Found 2026-10-31 setting up the release-pipeline worktree.

`scripts/install-git-hooks.mjs` treats `.git` as a directory. In a linked worktree `.git` is a file, so `mkdirSync(.git/hooks)` throws ENOTDIR and `npm ci` / `npm install` fail on `prepare`. Workaround in use: `npm ci --ignore-scripts`, then `npm run rebuild`, then `node node_modules/electron/install.js`.

Acceptance: in a linked worktree, `npm ci` succeeds and the hook installs into the common git dir from `git rev-parse --git-common-dir`, or is skipped with a message.
