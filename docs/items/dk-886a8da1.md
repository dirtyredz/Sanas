# install-latest.ps1 reports a version mismatch after a successful install


Found 2026-10-31 on the first real install of 0.1.1.

`scripts/release/install-latest.ps1` compares `VersionInfo.ProductVersion` (`0.1.1.0`, Windows' four-part form) with the release version `0.1.1` and throws "Installed version mismatch." after a successful install, so the run ends FAILED.

Acceptance: compare `FileVersion`, or normalise a trailing `.0`, so a correct install reports OK. A unit-level check of the comparison is enough; no real install is needed to verify.
