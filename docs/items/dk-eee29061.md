# Make MergePart hasLegacySlides and hasMeetingContext required so merge refusals can't fail open

From the v0.1.18 sign-off: merge-plan.ts:22-24 declares hasLegacySlides? and hasMeetingContext? optional, so a MergePart builder that forgets either silently skips both merge refusals. Make them required booleans so the compiler forces merge.ts toPart and tests to decide them.
