# Move screen-capture wiring out of meetings/index.ts


Source: structure review 2026-10-31 (componentization lens).

`src/main/services/meetings/index.ts` builds `createScreenCapture` with the overlay bounds, wires `CaptureRequests` and the draft store, and re-exports five capture functions. The orchestrator now knows the overlay window and capture internals.

Direction: a `createCaptureFeature` factory beside `createLiveControls`; index.ts takes the result the same way it takes `liveControls`. Split the capture status broadcaster (`current`/`seq`) out of `assist/capture-requests.ts` at the same time.
