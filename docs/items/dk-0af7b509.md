# Buffer PCM through reconnect backoff and replay it so a network blip leaves no gap

From docs/BACKLOG.md (P2 — Post-v1 ideas):

- [x] Buffer PCM through the provider's reconnect backoff and replay it, so a brief network
      blip does not leave an untranscribed gap (today those chunks reach the WAV only)

Implemented 2026-11-09: provider-owned, copied PCM FIFO capped at 30 seconds; original byte positions; paced oldest-first replay with bounded socket pressure; failed-send suffix retention; cancellable open/backoff/drain; explicit overflow-to-pause. Recording and meeting clock count accepted capture once. Audio already handed to the socket is not recoverable without provider acknowledgement. Fake-socket coverage includes retry/open/drain failures, mono/stereo offsets, normalization, pressure, overflow, Stop, retired events, and the combined identity/recording scenario.
