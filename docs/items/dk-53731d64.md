# Move the hotkey binding table out of lifecycle/start.ts


Source: structure review 2026-10-31 (componentization lens).

`src/main/lifecycle/start.ts` hosts `registerHotkeys()`, which binds each accelerator to meetings/overlay actions. That is feature wiring, not startup sequencing: adding a hotkey means editing the startup file.

Direction: `services/hotkeys/bindings.ts` owns the table; `start.ts` calls `registerHotkeyBindings()`. Related: dk-0a31a485 (pause/resume hotkey).
