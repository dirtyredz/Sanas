# Track talking-point coverage across the whole meeting for Next point


Next point coaching only knows the last 6,000 characters of transcript and the last three delivered next points, so it can suggest a talking point already covered earlier in the meeting. Track which job talking points / notes have been covered across the whole meeting (cheaply, without sending the whole transcript per call) and feed that to the coach. Follow-up to dk-f004d957.

Implementation: Start freezes a bounded catalog from job talking points and notes. Confirmed-user finals contribute complete quoted evidence with speaker/channel/audio provenance; Next point alone receives a bounded, relevant snapshot. Evidence survives the rolling window, coaching-off, pause/resume, reconnect and context Apply. Unpinning retracts that speaker; re-pinning can reconsider the current 200 finals. No extra inference calls, database migration, answer-prompt changes or speculative-equality relaxation.

Correction to the original description: current coaching uses a 2,500-character background, 2,000-character explanation and 1,000-character question, rather than a 6,000-character transcript. Historical coverage adds at most 3,000 characters. Local associations are incomplete evidence, never asserted semantic completion.
