# Detect completed turns before answering and coach the next point while I talk


Replace per-segment question detection with completed-turn detection and add opt-in "Next point" coaching while the user talks (plan: docs/plans/turn-detection-and-coach.md). Also adds the This-PC capture-health warning and the stereo pinSpeaker guard from the 2026-10-29 loopback diagnosis.

Acceptance:
- Fragmented finals assemble into one completed turn (Deepgram endpointing/UtteranceEnd + 350 ms grace, 1.8 s fallback); no classification on a first fragment alone.
- Loose local prefilter, then a fail-closed classifier (classifierModel, default Haiku) decides question/request/objection/none before any automatic answer.
- Opt-in Next point coach (coachWhileTalking) with its own cooldown, buffered delivery, cancelled by answers, hotkey, other speakers and disabling.
- Suggestion purpose (answer | next-point) persisted (migration v5) and labelled consistently in overlay, meeting history and export.
- Capture warning after ~5 s of exact-zero system audio while the mic is active; advisory only; coaching suppressed while it shows.
- Focused tests, typecheck, lint and build pass; living docs updated.
