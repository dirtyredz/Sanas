# One owner for the image-request token budget and retry policy


Source: structure review 2026-10-31 (abstraction lens).

- `manual-requests.ts` hard-codes `maxTokens: 2400` for detail requests, matching `CAPTURE_MAX_TOKENS` in `capture-prompts.ts` without referencing it.
- `claude.ts` forces `maxRetries = 0` whenever an image is present, duplicating the policy `manual-requests.ts` already sets.

Direction: one named budget constant (or a named detail budget with its reason); keep the retry decision in the request builder and have the provider just honour `req.maxRetries`.
